# Archived string-profile experiment

`profile_optimizer.py` is the exact text of optimizer.py at commit 48ae105,
retained as a standalone executable with the original two-file interface.
It is not the active submission policy. Its fixed-corpus gains, combined
tradeoffs and holdout losses remain recorded and tested.

Run `./experiments/profile_optimizer.py PROGRAM SCHEMA`. The active
`./optimize --joins-only PROGRAM SCHEMA` uses the simpler 3155414 model.
